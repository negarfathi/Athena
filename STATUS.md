## Justification

### Available

The artifact is publicly available through both a persistent archival repository and a public development repository.

- Zenodo DOI: [https://doi.org/10.5281/zenodo.19455305](https://doi.org/10.5281/zenodo.19455305)
- GitHub repository: [https://github.com/negarfathi/Athena](https://github.com/negarfathi/Athena)

The archived version is intended to provide long-term access, preservation, and citation for the artifact associated with the accepted paper.

### Functional

The artifact contains the Athena implementation together with the materials needed to install, run, and evaluate it. The repository includes documentation, execution scripts, benchmark material, and evaluation outputs that support exercising the artifact and reproducing the experimental workflow described in the paper.

### Reusable

The artifact is organized as a research software package rather than only a one-time paper supplement. It includes a documented implementation, runnable scripts, and benchmark materials, and Athena itself is structured as an end-to-end framework with distinct stages that can support reuse, extension, and comparative evaluation by other researchers.

## Notes

This artifact accompanies the accepted FSE 2026 paper and is intended to support evaluation of the implementation and experiments described there. Third-party tools, dependencies, and benchmark suites referenced or included by the artifact remain subject to their own licenses and terms.
